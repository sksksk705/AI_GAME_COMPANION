# 동료 · AI Game Companion

**게임을 함께 보고, 지난 이야기를 기억하고, 자연스럽게 대화를 이어가는** 개인용 데스크톱 초안이다. [Questie](https://www.questie.ai/ko/features)의 화면 관찰·대화·기억 경험을 참고했으며, 사용자 선택에 따라 텍스트부터 다듬는다. 게임 이름은 자유롭게 입력한다. Anno 홉 무역로는 선택해서 여는 예제다. [제품 계획](PLAN.md), [행동 명세](docs/COMPANION_BEHAVIOR.md), [구현 기록](docs/PROTOTYPE.md)을 함께 따른다.

## 실행

Windows 10 이상과 Node.js 22.12 이상을 기준으로 한다. 이 작업 PC에서는 Electron 실행 파일을 설치했고 실행을 검증했다.

```powershell
npm install
npm start
```

Electron이 첫 실행에 실행 파일을 다운로드할 수 있다. React·빌드 도구·외부 DB는 필요 없다. 앱의 Node.js/SQLite 실행은 Electron 내장 런타임을 사용한다.

## 처음 사용하기

1. 새 설치는 `첫 플레이`에서 시작한다. 왼쪽 `＋`에서 게임과 세이브·런 이름을 입력한다. 목표는 선택 사항이다. 이전 초안의 홉 월드와 기록은 보존한다.
2. `연결과 설정`에서 자신의 AI 키와 모델을 연결한다. 화면을 공유하지 않아도 잡담과 이전 이야기를 이어갈 수 있다.
3. “아, 또 막혔네”, “이번엔 됐다”, “오늘은 탐험만 하자”처럼 편하게 말한다. Enter는 보내기, Shift+Enter는 줄바꿈이다. 기본 대사는 짧고, 근거와 자세한 생각은 펼쳐본다.
4. `말투 설정`에서 동료 이름, 성향, 반말·존댓말, 힌트 등 선호를 고른다. 게임에서 `Ctrl+Shift+G`를 누르면 게임 위 오버레이에 바로 입력한다. `게임 위 오버레이` 버튼으로 미리 띄워둘 수도 있다.
5. 먼저 말하는 방식은 `부르면 대답`·`목표 지켜보기`·`함께 플레이`에서 고른다. 먼저 반응하려면 화면 관찰과 설정의 자동 AI 확인도 켜야 한다. 모드 선택만으로 외부 전송을 켜지 않는다.

### 게임 위에서 대화하기

- 앱을 실행한 채 게임에서 `Ctrl+Shift+G` → 질문 입력 → `Enter`. 보내면 바로 게임으로 돌아가며, 답변은 오버레이에 표시된다. `Shift+Enter`는 줄바꿈이다.
- `Esc` 또는 같은 질문 단축키를 다시 누르면 작성 중인 질문을 보존하고 게임으로 돌아간다. 진행 중인 AI 요청도 계속된다. 취소는 입력 모드에서 `취소`를 누른다.
- 평소 오버레이는 클릭을 아래 게임 창으로 통과시킨다. 답변 도착으로 게임의 키보드 입력을 가져오지 않는다. 입력 모드에서는 위쪽 제목을 끌어 위치를 바꾸고 이미지 근거를 열어볼 수 있다.
- 다른 창을 직접 선택하면 입력 모드를 닫고 그 창을 유지한다. 질문하지 않고 오버레이를 숨기거나 다시 표시해도 현재 게임 창의 입력을 유지한다.
- `Ctrl+Shift+H`는 오버레이 숨기기/다시 표시, `큰 창`은 설정·기억·게임 창 선택으로 복귀한다. 질문 단축키는 숨겨진 상태에서도 입력창을 연다.
- 다른 앱이 단축키를 사용 중이면 질문은 `Ctrl+Shift+F8`, 숨기기는 `Ctrl+Shift+F9`로 대체한다. 실제 사용할 키를 오버레이 상단과 설정에 표시한다. 질문 키를 모두 등록하지 못하면 클릭 통과를 끄고 마우스 입력을 유지한다.
- 창 모드·테두리 없는 전체 화면을 기준으로 한다. 독점 전체 화면과 관리자 권한이 다른 게임은 별도 검증이 필요하다. 독점 전체 화면에서 보이지 않으면 게임의 표시 방식을 테두리 없는 전체 화면으로 바꾼다.
- 오버레이에서도 선택한 창의 관찰과 현재 플레이의 대화·기억을 이어간다. 화면 관찰은 큰 창에서 직접 시작한다. 모델의 응답 속도는 그대로이며, 분석 중에도 게임을 계속할 수 있다.

처음부터 오버레이로 시작하려면 `npm start -- --overlay`를 사용한다. 앱이 Win32 창 전환 기능을 직접 호출해 질문 직전의 창을 기억하고 복귀한다. Windows API 연결에는 `koffi`를 사용하며 `npm install`에 포함된다. 별도 보조 프로그램이나 게임 프로세스 주입은 사용하지 않는다.

### 홉 무역로 예제

왼쪽 `Anno 홉 운송 예제 열기`에서 기존 사례를 연다. `Anno 예제 · 홉과 무역로` 안의 빠른 질문은 **로컬 가이드**이며 AI 응답이 아니다. 6단계 안내, 공급망 개념도, 관찰한 수치로 계산하는 최소 선박 수, 제안·수락·적용·해결 구분을 유지한다. 다른 게임이나 일반 Anno 플레이에 이 튜토리얼을 자동으로 붙이지 않는다.

### 화면 관찰

- `실시간 게임 창` → `창 선택` → 미리보기 확인 → `관찰 시작`. 전체 화면이나 오디오는 수집하지 않는다.
- 선택한 창의 스트림에서 초당 1회 화면을 수집한다. 최근 60장만 임시 보관하고, 변화 후보는 최소 15초 간격으로 근거를 저장한다.
- `화면 기록` 또는 `Ctrl+Shift+Space`로 즉시 근거 화면을 남긴다.
- 창 캡처 종료, 기기 잠금·대기, 월드 변경, 앱 종료 시 관찰을 중지한다. 중지하면 임시 버퍼를 비운다.
- `영상 리플레이`는 영상 당시의 자료다. 현재 게임 상태나 실시간 관찰로 표시하지 않으며 선제 대화의 현재 근거로 사용하지 않는다.
- 제공한 MP4가 프로젝트 루트에 있으면 자동으로 선택할 수 있다. 다른 영상은 `영상 선택`으로 불러온다. 원본 영상은 Git에서 제외한다.
- 이 PC에서 직접 확인한 영상 00:28의 근거 화면이 있으면 처음 만든 사례 월드에 한 번 등록한다. 다른 월드에는 복사하지 않는다. 새 체크아웃에 이 로컬 이미지가 없어도 영상 선택과 관찰 기능은 동작한다.

### AI 연결

도움 요청은 짧은 대사, 바로 할 행동 하나, 근거 이미지로 읽는다. 이미지를 누르면 영역 확대와 원본 비교가 열리며 `잘못 짚었어`로 같은 이미지를 연결한 정정 질문을 준비한다. 실제 모델의 [가이드·예시 이미지 평가](docs/GUIDE_EVALUATION.md)도 참고한다.

`연결과 설정`에서 OpenRouter 키를 입력하고 모델 목록을 가져온 뒤 이미지·구조화 답변 지원 모델을 선택한다. 키를 채팅이나 소스에 적지 않는다.

현재 작업 PC에서는 `OpenAI: GPT-6 Luna Pro` (`openai/gpt-6-luna-pro`)를 연결했다. 작은 이미지 요청과 짧은 한국어 대화를 실제로 확인했으며, 대화 응답은 약 11초였다. 새 설치에서는 자신의 키와 모델을 연결한다.

원본 게임 이미지를 넣은 평가에서는 약 24~45초가 걸렸다. 짧은 연결 테스트의 시간을 실시간 게임 응답 성능으로 해석하지 않는다.

- 화면·관련 기억 전송은 별도 체크박스로 허용한다. 새 키·모델은 1픽셀 이미지로 실제 요청 한 번을 성공시킨 후 저장한다. 테스트 요청도 비용·요청 한도에 포함한다.
- Windows에서는 Electron `safeStorage`의 OS 암호화로 키를 보호하고 암호문 파일만 저장한다. 렌더러·SQLite·내보내기에는 키를 반환하지 않는다.
- 대화에는 해당 플레이의 최근 12턴, 관련 목표·사용자 기억, 최대 두 근거 이미지를 연결한다. 잡담에는 화면이 필수가 아니다. 좌표·근거 ID·월드·맥락 리비전을 검증하며 모델 추정을 확정 기억으로 바꾸지 않는다.
- 선택한 기록으로 질문할 때는 그 이미지 한 장을 전달한다. Anno 예제는 검토한 일반 가이드와 열람 단계를 함께 전달하며, 개념 설명과 영상에서 읽은 사실을 구분한다.
- 자동 확인은 기본 OFF, 간격은 15·30·60·120초 중 선택하며 기본 30초다. 먼저 말하기는 최신 게임 창 근거, 사건·모드·목표 관련성, 집중 상황, 사용자 입력, 반복·빈도 제한을 모두 통과해야 한다. 부르면 대답 모드에서는 기록만 남긴다. 침묵한 분석도 비용·한도를 사용한다.
- 선제 대화는 최소 60초 간격, 10분 최대 3회, 같은 사건은 5분간 억제한다. `이 반응은 그만`을 누르면 같은 사건은 현재 관찰 세션에서 다시 말하지 않는다. 표현이 달라진 동일 사건이나 빠른 전투의 인식은 실제 플레이 검증이 필요하다.
- 일일 요청 한도는 한국 시간 기준 기본 20회다. 사용량 메타데이터는 별도 원장에 저장하므로 월드 삭제로 요청 한도가 초기화되지 않는다. 제공자가 보고한 비용과 미확인 비용을 구분한다.
- 실패·취소·시간 초과는 자동 재전송하지 않는다. 이미 전송된 요청의 청구가 취소된다고 보장하지 않는다. 월드·목표·전송 설정 변경 뒤 이전 답변을 새 맥락에 적용하지 않는다.

### 기억과 보관

월드별 목표, 계획 상태, 계산 입력, 사용자 기억, 대화, 관찰 세션, 근거 이미지를 SQLite와 로컬 파일에 보관한다. 앱을 다시 실행해도 남는다.

`월드 기억`에서 검색·추가·수정·삭제할 수 있다. 기억이나 화면을 수정·삭제하면 그 근거를 사용한 답변 및 파생 답변도 검색과 대화에서 제거한다. 목표 변경 이력은 과거 기록으로 유지한다.

앱의 요청 횟수·모델·제공자 보고 비용 원장은 월드 기억과 별개다. 월드를 삭제해도 그날의 사용량과 요청 한도는 유지된다. 원장에는 화면·질문·API 키 원문을 저장하지 않는다.

근거는 총 300장, 30일 보관한다. 기간 정리는 앱 시작 시 수행한다. 한도 도달 시 기록을 지우라는 상태를 표시하고 캡처를 중지한다. 관찰 버퍼는 전체 플레이 영상을 영구 저장하지 않는다.

`기록 내보내기`는 현재 월드의 기록·이미지·표시 정보를 버전 있는 JSON으로 내보낸다. 키·인증 토큰은 제외한다. 가져오기 UI는 후속 작업이다. 실제 저장 위치는 OS의 `AI Game Companion` 사용자 데이터 폴더다.

## 검증

```powershell
npm test
npm run smoke
```

`npm test`는 최근 대화 순서, 침묵 후보 제외, 범용 게임·성향 설정, 선제 반응의 최신성·집중·중복·빈도 제한, 기존 계산·기억·경계와 모의 제공자 요청을 확인한다.

`npm run smoke`는 별도 임시 프로필로 앱을 실행한다. 대화 표시·침묵·반응 거절·말투·오버레이·자유 게임 입력·기억 격리와 기존 Anno 예제를 확인한다. **테스트용 창이 잠시 보이며, Windows 입력 권한을 얻기 위해 시험 앱 내부를 한 번 클릭하고 마우스 위치를 복원한다.** 별도 프로세스의 창으로 Windows 전경 복귀, 클릭 통과 플래그, Esc·Enter·전송 중 플레이·답변 도착 시 포커스 유지·사용자가 다른 창을 선택한 경우·질문하지 않은 상태의 숨기기·단축키 충돌 대체를 확인한다. 테스트 창 및 로컬 영상의 실제 캡처가 오버레이에서도 계속되는지 검증한다. 대화 문장은 명시적으로 표시한 UI 시험 데이터이며 유료 AI 요청은 하지 않는다.

현재 검증 결과와 남은 범위는 [초안 구현 기록](docs/PROTOTYPE.md)에 정리했다. 실제 게임 장시간 관찰, AI 인식 품질, 설치·업데이트 배포가 완료된 제품은 아니다.
