# 가이드와 예시 이미지 평가 · 2026-10-07

기대값은 **옆에서 화면을 같이 보며, 지금 할 행동 하나를 짚고, 실제 화면과 설명을 연결하는 동료**다. 가이드를 많이 출력하는 것만으로 충족하지 않는다. 기본 동작은 범용 텍스트 대화이며 Anno 홉 운송은 이를 검증하는 선택 사례다.

## 평가 자료와 방법

- 사용자 영상 00:28 원본, 1920×1080. 소형 교역소, 홉 7/75, 구매·판매용 무역 옵션 팝업을 직접 확인했다. 새 항로 편집 화면은 없다.
- 사용자가 선택한 `openai/gpt-6-luna-pro`에 학습 시작·팝업 식별·배 수 판단·다른 게임의 잡담을 개선 전후 각 1회 요청했다. 마지막으로 무역로 진입 방법을 보강하고 학습 시작을 1회 더 확인했다. 총 9회이며 장시간 품질의 통계적 검증은 아니다.
- 프롬프트·같은 사례 자료·실제 구조화 응답을 비교하고, UI의 원본 확대와 표시 위치를 직접 확인했다. `.local/evaluation-before.json`, `evaluation-after.json`, `evaluation-after-learn.json`에 원문·시간·제공자 비용을 보관한다. 키는 포함하지 않는다.

## 반영한 변경

1. 선택한 사례의 검토된 일반 가이드와 현재 열람 단계를 모델에 전달한다. 단계를 열었다는 이유로 게임에서 완료했다고 해석하지 않는다.
2. 도움 요청의 다음 행동을 기본 대화에 노출한다. 잡담에는 행동 목록을 붙이지 않는다.
3. 근거 이미지를 대화에서 바로 보여주고 영역 확대·원본 비교·“잘못 짚었어”를 제공한다. 번호는 작은 미리보기에서도 읽을 수 있게 표시한다.
4. 답변마다 자신의 표시를 사용한다. 다른 답변의 최신 표시로 바꾸지 않는다. 선택한 기록으로 질문하면 그 이미지 한 장을 전달하고 다른 월드 이미지 요청을 차단한다.
5. 기록·현재 화면·AI 표시·설정 개념 예시를 구분한다. 홉 전용 칸과 생활물품 칸의 적재/하역 표는 게임 UI 재현으로 표시하지 않는다.
6. 예제 원본의 재고 영역을 좁히고 미니맵 아래 무역로 진입 아이콘을 추가했다. 기존 두 표시의 예제 기록도 업데이트하며 원본은 유지한다.

## 검증 결과와 한계

`npm test`와 `npm run smoke` 통과. UI 시험은 근거 카드, 상세 밖의 다음 행동, 확대, 답변별 표시, 정정 이미지 연결, 개념 예시 표시, 월드 전환 시 선택 해제, 지정 이미지 전송과 다른 월드 이미지 차단을 확인한다. UI 시험의 응답은 모의 데이터이며 실제 모델 평가 9회와 구분한다. 실제 모델 응답을 별도 시험 프로필에 재현한 화면은 `.local/guide-preview.png`, `.local/evidence-preview.png`에 보관했다.

최종 학습 시작 응답은 약 29초였다. 원본 게임 이미지 요청들은 약 24~45초, 화면 없는 잡담은 약 7~12초였다. 이 정도 대기는 자연스러운 실시간 동료 경험의 남은 약점이다. 같은 Pro 모델을 유지했고 응답 속도가 해결됐다고 주장하지 않는다. 9회 평가의 제공자 보고 비용 합계는 $0.02008196이다.

실제 새 항로 화면·생산 통계·선박 적재량·왕복 시간은 아직 없다. 따라서 편집 화면의 정확한 버튼 위치와 실제 필요한 척수, 적용 후 공급 안정은 검증하지 않았다. 작은 글씨의 AI 좌표 정확도와 다양한 게임의 긴 대화도 추가 검증 대상이다.
