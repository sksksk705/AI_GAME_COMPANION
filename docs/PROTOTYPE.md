## 확인한 근거

[Questie 기능](https://www.questie.ai/ko/features), [FAQ](https://www.questie.ai/ko/faq), [프롬프트 안내](https://www.questie.ai/prompting)의 화면을 함께 보고 자연스럽게 대화하며 기억을 이어가는 경험을 참고했다. 캐릭터 카탈로그·파티·음성·서비스 가입·공개 성능 수치는 복제하거나 검증하지 않았다. 현재는 사용자가 고른 텍스트 흐름에 집중한다.

첨부 영상은 로컬에서 열 수 있었다. 41.36초, 1920×1080, 60fps다. 여러 시점의 대표 프레임과 00:28 원본 프레임을 확인했다. 00:28에는 선택한 소형 교역소, 홉 재고 7/75 및 무역 옵션 패널이 보인다. 이 항구의 구매·판매 패널을 섬 간 자동 운송 무역로 화면으로 설명하지 않는다.

정확한 무역로 편집 화면, 홉 생산·소비량, 선박 적재량, 실제 왕복 시간은 확인하지 못했다. 따라서 실제 필요한 배 수, 현재 생산 병목, 항로 완료 여부는 확정하지 않는다. 영상의 일부 프레임 확인을 전체 영상 분석이나 AI 인식 검증으로 보고하지 않는다.

일반 게임 안내는 제공한 사례와 개발사 설명을 참고했다. 현재 사용자 버전·모드와 정확한 UI 문구 검증은 남아 있다.

- [개발사: 일반 무역로와 용선 항로](https://www.anno-union.com/devblog-your-own-trading-empire/)
- [개발사: 노동력과 섬별 작업 조건](https://www.anno-union.com/devblog-working-conditions/)
- [개발사: 섬별 비옥도](https://www.anno-union.com/devblog-treasures-of-the-soil/)

기술 API는 [Electron 창 캡처](https://www.electronjs.org/docs/latest/api/desktop-capturer), [보안](https://www.electronjs.org/docs/latest/tutorial/security), [safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage), [SQLite](https://nodejs.org/api/sqlite.html), [OpenRouter 구조화 응답](https://openrouter.ai/docs/guides/features/structured-outputs), [Win32 전경 창 전환](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow), [Koffi Windows API 호출](https://koffi.dev/start)을 확인했다. 공개 모델 목록의 이미지·구조화 지원 필터가 실제 응답에서 동작하는 것도 확인했다.

## 남은 검증과 다음 작업

### DRAFT-03 — 장기 기억·공동 학습·경험 기록

- 연결: FR-05–08·10·24–25, AT-39–40의 회귀 사례 및 AT-37–38·42의 저장·맥락 구성 부분. 실제 게임의 학습 품질·인식·실시간 위치 표시는 완료 범위가 아니다.
- 장기 기억: 최근 12턴 밖의 사용자 발화와 당시 AI 답변도 월드별 검색 대상에 포함한다. 키워드 접두어·일부 한국어 조사 정리로 시작하며 의미 검색 전체를 보장하지 않는다. 미전달 자동 후보는 모델의 대화 기억에서 제외한다.
- 보관: 자동 이미지 만료는 원본만 제거하고 만료 메타데이터와 대화·선택·경험을 유지한다. 사용자 직접 삭제·정정의 파생 자료 처리와 분리했다. 표시 중인 답변·경험의 근거는 최근 100개 기록 제한과 별개로 조회한다.
- 공동 학습: 프롬프트를 별도 모듈로 분리하고 관찰·가설·작은 변경·확인 조건을 지시한다. 검색된 경험의 사용자 선택·보고, 과거 AI 제안, 근거 만료를 구분해 전달한다. 관련 시도 전 캡처가 있으면 최근 이미지와 함께 제공하며 지정 이미지 질문은 한 장을 유지한다.
- 경험: 모델의 `learning_proposals`는 후보 상태로만 저장한다. 같은 진행 제안은 재사용하고, 미전달 자동 답변에서 실행할 경험을 생성하지 않는다. 제안·답변 저장은 원자적으로 처리한다. 게임별로 별도 코어를 만들지 않았다.
- UI: 대화·`함께 배우는 경험`·월드 기억에서 후보, `해보기`, `적용했어`, `결과 남기기`, 보류·거절·직접 추가·내용 수정·삭제를 연결했다. 결과는 사용자 보고이며 개선·변화 없음·악화·미확인을 구분한다. 모델이 적용·성공 상태를 쓰지 못하도록 입력을 검증한다.
- 저장 호환: 기존 SQLite `records`에 경험 종류와 JSON 필드를 추가하는 방식으로 시작한다. 기존 대화·월드는 유지한다. 경험 진행은 앞선 대화를 보존하고, 내용 정정·삭제는 관련 파생 답변에도 반영한다. 수정 리비전과 월드 맥락 변경을 검사한다.
- 검증: 클라우드 Node.js 24.19.0에서 `node test/check.cjs` 통과. 기존 시험과 `test/learning.cjs`의 장기 회수·재시작·이미지 만료·참조 조회·상태·정정·삭제·롤백·제공자 맥락 시험을 실행했다. 제공자 응답은 모의 데이터다.
- UI 검증: 클라우드 headless Chromium에서 실제 `renderer.js`·HTML·CSS와 SQLite를 연결하고 IPC는 시험 브리지로 대체했다. 직접 추가·수락·적용·결과·새로고침 복원·정정·월드 전환 시 편집 닫기·100장 이후 근거 확대·만료 안내를 확인했다. 게임 창 캡처나 Electron IPC·Windows 포커스 검증을 뜻하지 않는다. 화면 확인 자료는 로컬 `.local/learning-ui-check.png`이며 Git에 포함하지 않는다.
- 실행 한계: 이 클라우드의 `npm test`는 Electron 실행 파일 다운로드에서 `fetch failed`로 차단됐다. 새 변경의 실제 Windows 오버레이·캡처·유료 모델 반응은 재검증하지 않았다. 이전 절의 Windows·실제 API 결과는 DRAFT-01/02의 기존 기록이다.

### DRAFT-04 — 동료 아이콘·말풍선

> 당시 구현 기록이다. 로컬 인사 기능은 DRAFT-05에서 사용자 수정 요청에 따라 제거했다.

- 연결: FR-27, AT-43. 사용자가 선택한 아이콘+말풍선 형태로 기존 대화 오버레이를 변경했다. 아이콘을 눌러 질문창을 펼치고 보내기·Esc로 접는다. 위로 펼치는 창 위치, 초안 보존, 큰 창·숨기기·설정·질문 단축키를 유지한다.
- 표시: 투명 창에 기본 캐릭터와 대기·관찰·생각 중 연출을 구현했다. 새 답변은 20초짜리 말풍선과 실제 근거 이미지의 미리보기로 보이며 대화에서 계속 조회한다. 호버 시 마우스 대상만 활성화하고 키보드 포커스는 명시적으로 대화를 열 때만 받는다. 투명한 빈 영역은 게임으로 클릭을 통과시킨다.
- 먼저 말하기: 함께 플레이 모드에서 끌 수 있는 짧은 로컬 인사를 추가했다. 실제 게임 사실을 말하지 않으며 API 요청·학습 기억을 만들지 않는다. 관찰 세션·실시간 최신 캡처·질문/분석 대기 없음·최소 4분·세션 최대 3회·AI와 공유하는 발언 한도를 검사한다. 게임 상황에 대한 AI 선제 발언은 기존 검증을 유지한다. 느린 모델 응답의 최신성 재검증은 후속 작업이다.
- 클라우드 검증: `node test/check.cjs` 통과. 정책 검사에 멀티 모니터 경계·아이콘 영역/빈 영역·모드/허용/관찰/리플레이/초점/최신성/빈도 조건을 추가했다. 시스템 Chromium에서 실제 HTML/CSS/renderer와 SQLite를 사용하고 IPC를 모의 구현해 아이콘 클릭·접기·초안·이미지 확대·대기·전송·인사 설정·다른 세션/월드·숨기기와 기존 경험 기록 흐름을 확인했다. 화면은 명시적인 시험 데이터다.
- 실행 한계: 이 변경의 `npm test`도 Electron 실행 파일 다운로드에서 `TypeError: fetch failed`로 중단됐다. Node 직접 실행과 브라우저 검증만 통과했다.
- 미검증: 변경한 Electron 투명 창, 실제 Windows 마우스 히트 테스트·포커스·DPI·드래그·게임 호환성은 이 클라우드에서 실행하지 못했다. `npm run smoke`에 실제 아이콘 클릭·호버/빈 영역의 Windows 플래그·이미지 말풍선 시나리오를 추가했으며 실제 PC에서 실행해야 한다. 유료 API·실제 Anno 캡처를 이 변경에서 시험하지 않았다.

### DRAFT-05 — 조언·인사보다 게임의 순간에 반응

- 연결: FR-28·AT-44. 정기 인사 타이머·문구·설정·IPC 이벤트를 제거했다. 함께 플레이의 자동 답변은 전후 게임 변화에 대한 1~2문장 반응으로 제한하며 자동 조언·질문·학습 과제를 전달하지 않는다. 직접 요청한 도움과 경험 기록은 유지한다.
- 근거: 같은 월드·창·세션·관찰 연속성·해상도의 15~45초 간격 전후 캡처 두 장을 제공한다. 픽셀 차이는 모델 확인 후보로만 쓰며 `observed_change`·각 이미지의 사실·시점·세션을 검증한다. 비교 가능한 변화가 없으면 침묵하도록 지시한다.
- 늦은 반응: 45초 응답도 최근 기록 사건의 반응으로 전달할 수 있다. 이후 현재 사실로 재검증한 것은 아니다. 이후 장면 시각 표시, 원본 이미지, 최대 75초 사건 나이, 최근 5초 캡처, 세션·공백·해상도·전체 장면 변화 검사, 사용자 입력·집중·거절·쿨다운·빈도를 적용한다. 목표 감시의 현재 근거 15초 정책은 유지한다.
- 비용: 함께 플레이/목표 감시·실시간 창·전송 및 자동 확인 허용에서만 자동 요청을 시작한다. 조용한 모드·리플레이·숨김/최소화·입력·진행 요청·발언 한도에서는 요청하지 않는다. 침묵/보류 후 간격을 설정의 2배·4배, 최대 120초로 늘린다. 허용·일일 한도를 자동으로 상향하지 않는다.
- 검증: `node test/check.cjs`의 실제 SQLite·모의 제공자로 두 이미지의 시간순 맥락·변화 검증·45초 지연·75초 만료·공백/세션/초점/중복·자동 요청 정책·관찰 시점 기억 전달을 확인했다. 시스템 Chromium의 실제 렌더러/SQLite·모의 IPC에서 게임 반응과 시각·이후 이미지 미리보기·전후 근거 두 장·자동 행동 없음·인사 설정 제거·관찰 중지·모드/다른 세션·월드 경계·기존 대화/경험 UI를 확인했다.
- 한계: 화면 데이터와 제공자 응답은 시험용이다. 실제 게임 의미 인식·새 스키마의 유료 모델 응답·Windows 포커스/클릭 통과를 이 클라우드에서 검증하지 않았다. 현재 위치 정렬·의미 수준의 최신 대상 재검증은 후속 범위다. 샘플 간의 짧은 사건이나 긴 화면 전환은 놓칠 수 있다. 이 변경의 `npm test`도 Electron 실행 파일 다운로드에서 `TypeError: fetch failed`로 중단됐다.

### 실제 PC에서 이어갈 확인

1. 사용자의 실제 Anno 창에서 최소화·창 종료·UI 배율·해상도 변경·장시간 플레이의 성능과 관찰 공백을 검증한다. 선택한 창 스트림에 관한 기본 시험만 끝났다.
2. 실제 게임 이미지 요청의 인식·근거·표시·비용을 확인한다. GPT-6 Luna Pro의 작은 이미지와 텍스트 대화 요청은 검증했으며, 실제 게임 화면 인식과 장시간 대화 품질 검증은 남아 있다.
3. 실제 무역로와 생산 통계 화면을 확보해 단계별 버튼 위치 및 해당 월드의 선박 수를 확인한다.
4. 변화 감지는 전체 화면 밝기 비교다. 카메라 이동과 애니메이션을 의미 있는 사건으로 확정하지 않는다. 실제 실패 사례가 쌓이면 게임 관심 영역/OCR을 추가한다.
5. 목표 감시·함께 플레이의 실제 모델 판단과 방해 정도, 이름이 달라진 동일 사건의 중복, 장시간 대화의 기억 검색 품질을 검증한다. 현재 구조화된 모델 후보와 단순 사건 키에 기반하며 실제 플레이 정확도를 주장하지 않는다.
6. 음성 양방향 대화, 정밀 배치, 가져오기, 버전·모드 상세 입력, 계정·동기화·서비스 운영·배포는 후속 범위다. 자유 게임 이름 지원이 모든 게임의 규칙·위치를 정확하게 해석한다는 뜻은 아니다.

전체 P0–P4 완료, AT 전체 통과, 서비스 출시로 표시하지 않는다. 개인용 초안에서 실험할 수 있는 기능과 미검증 범위를 구분한다.
