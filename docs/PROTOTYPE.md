- 연결: FR-01–08·10–11·22–24, AT-03–08·10·28–29·32–35 및 홉 사례의 통과 조건.
- 목표: 임의의 게임에서 함께 보기·짧은 대화·지난 이야기와 기억·선택적 상황 반응을 연결한다. 사용자 요청은 범용 게임 동료이며, 후속 확인에서 텍스트 우선으로 정했다.
- 스택 선택: Windows + Electron 44.5.1, 일반 HTML/CSS/JavaScript, Electron 내장 SQLite. React·TypeScript는 후보였으며 이 초안에서는 별도 빌드 도구 없이 구현했다.

## 확인한 근거

[Questie 기능](https://www.questie.ai/ko/features), [FAQ](https://www.questie.ai/ko/faq), [프롬프트 안내](https://www.questie.ai/prompting)의 화면을 함께 보고 자연스럽게 대화하며 기억을 이어가는 경험을 참고했다. 캐릭터 카탈로그·파티·음성·서비스 가입·공개 성능 수치는 복제하거나 검증하지 않았다. 현재는 사용자가 고른 텍스트 흐름에 집중한다.

첨부 영상은 로컬에서 열 수 있었다. 41.36초, 1920×1080, 60fps다. 여러 시점의 대표 프레임과 00:28 원본 프레임을 확인했다. 00:28에는 선택한 소형 교역소, 홉 재고 7/75 및 무역 옵션 패널이 보인다. 이 항구의 구매·판매 패널을 섬 간 자동 운송 무역로 화면으로 설명하지 않는다.

정확한 무역로 편집 화면, 홉 생산·소비량, 선박 적재량, 실제 왕복 시간은 확인하지 못했다. 따라서 실제 필요한 배 수, 현재 생산 병목, 항로 완료 여부는 확정하지 않는다. 영상의 일부 프레임 확인을 전체 영상 분석이나 AI 인식 검증으로 보고하지 않는다.

일반 게임 안내는 제공한 사례와 개발사 설명을 참고했다. 현재 사용자 버전·모드와 정확한 UI 문구 검증은 남아 있다.

기술 API는 [Electron 창 캡처](https://www.electronjs.org/docs/latest/api/desktop-capturer), [보안](https://www.electronjs.org/docs/latest/tutorial/security), [safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage), [SQLite](https://nodejs.org/api/sqlite.html), [OpenRouter 구조화 응답](https://openrouter.ai/docs/guides/features/structured-outputs), [Win32 전경 창 전환](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow), [Koffi Windows API 호출](https://koffi.dev/start)을 확인했다. 공개 모델 목록의 이미지·구조화 지원 필터가 실제 응답에서 동작하는 것도 확인했다.

## 남은 검증과 다음 작업

1. 사용자의 실제 Anno 창에서 최소화·창 종료·UI 배율·해상도 변경·장시간 플레이의 성능과 관찰 공백을 검증한다. 선택한 창 스트림에 관한 기본 시험만 끝났다.
2. 실제 게임 이미지 요청의 인식·근거·표시·비용을 확인한다. GPT-6 Luna Pro의 작은 이미지와 텍스트 대화 요청은 검증했으며, 실제 게임 화면 인식과 장시간 대화 품질 검증은 남아 있다.
3. 실제 무역로와 생산 통계 화면을 확보해 단계별 버튼 위치 및 해당 월드의 선박 수를 확인한다.
4. 변화 감지는 전체 화면 밝기 비교다. 카메라 이동과 애니메이션을 의미 있는 사건으로 확정하지 않는다. 실제 실패 사례가 쌓이면 게임 관심 영역/OCR을 추가한다.
5. 목표 감시·함께 플레이의 실제 모델 판단과 방해 정도, 이름이 달라진 동일 사건의 중복, 장시간 대화의 기억 검색 품질을 검증한다. 현재 구조화된 모델 후보와 단순 사건 키에 기반하며 실제 플레이 정확도를 주장하지 않는다.
6. 음성 양방향 대화, 정밀 배치, 가져오기, 버전·모드 상세 입력, 계정·동기화·서비스 운영·배포는 후속 범위다. 자유 게임 이름 지원이 모든 게임의 규칙·위치를 정확하게 해석한다는 뜻은 아니다.

전체 P0–P4 완료, AT 전체 통과, 서비스 출시로 표시하지 않는다. 개인용 초안에서 실험할 수 있는 기능과 미검증 범위를 구분한다.
