    연결과 설정

    로컬 관찰과 외부 AI 분석은 별도로 제어해요.

    OpenRouter 연결

    미연결

    API 키는 이 PC의 OS 보안 기능으로 보호해요. 선택한 화면과 관련 기록은 OpenRouter 및 모델 제공자에게 전송되며 외부 비용이 발생할 수 있어요.

    모델 가격은 제공자 정보이며 실제 청구액을 보장하지 않아요.

    자동 확인은 기본 OFF예요. 먼저 말하기는 함께 플레이 또는 목표 지켜보기를 고른 경우에만 실행해요. 함께 플레이는 전후 화면의 게임 변화에 반응하며, 변화가 없으면 확인 간격을 늘려요. 침묵하는 확인에도 비용과 요청 횟수가 들어요. 초 단위 전투 코칭은 지원하지 않아요.

    오늘 요청 0회 · 비용 미확인

    새 키·모델 연결 시 1픽셀 테스트 이미지로 실제 요청을 한 번 보내요. 실패·시간 초과는 자동 재전송하지 않아요.

    관찰과 보관

    선택한 창을 초당 1회 캡처하고 최근 60장만 임시로 보관해요. 변화 후보와 직접 기록한 화면은 최대 300장·30일 보관해요. 관찰을 중지하면 임시 버퍼를 비워요.

    창 종료·잠금·플레이 변경 시 관찰을 중지해요. 즉시 화면 기록: Ctrl + Shift + Space. 오버레이의 실제 질문·숨기기 단축키는 아래에 표시해요.

    게임 위 오버레이는 창 모드·테두리 없는 전체 화면에서 사용해요. 보이지 않으면 게임의 표시 방식을 테두리 없는 전체 화면으로 바꿔주세요. 동료 이름을 끌어 위치를 옮겨요. 동료를 누르면 질문창이 열려요. Enter로 보내면 답변을 기다리는 동안 게임을 계속해요. 음성·게임 자동 조작·정밀 설계·배포는 후속 범위예요.

    세이브와 런마다 따로 기억해요
